Night Noodle Scheduler

Night Noodle Scheduler is a private, single-user tool that schedules the owner's own short videos to the owner's own YouTube channel and TikTok account. It runs only on the owner's computer and is not offered to the public.

How it uses YouTube

This tool uses YouTube API Services to upload videos (and their thumbnails) to the connected YouTube channel at scheduled times. By using it you agree to the YouTube Terms of Service.
